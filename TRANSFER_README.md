# IPF Factory — SME Programme Transfer

This repository contains the reusable JUMP platform source, prepared for transfer and repurposing under IPF Factory.

## Important

- Do not commit `.env` files, API keys, database URLs, OAuth secrets, payment credentials, or private tokens.
- Recreate all production secrets in the IPF-owned environment.
- Migrate participant data and uploaded files separately through an approved, secure process.
- The current live JUMP deployment remains unchanged until the IPF version has passed acceptance testing.

See `IPF_FACTORY_HANDOVER_PLAN.md` for the complete migration route.
